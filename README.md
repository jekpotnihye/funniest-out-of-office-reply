# Funniest One-Line Out-of-Office Reply

A single out-of-office email auto-reply, one line long, written to be
funny on a first read and still usable as a real away message.

Entry (76 characters, no trailing newline):

> Out of office until Monday; the same spreadsheet is in charge, unsupervised.

## Run

```sh
python3 main.py
```

The program writes the entry verbatim to `/output/entry.txt`
(`OUTPUT_PATH` overrides the destination for local checks).
It needs no arguments, no network, and no dependencies beyond
Python 3's standard library.

## Why this line

It opens as a plain away message, names a specific, recognisable
office stand-in, and lands its twist in the last word. It stands
alone, needs no signature or name, and avoids the usual beach,
inbox, and limited-email turns.
